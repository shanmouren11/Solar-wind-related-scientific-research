# 数据目录与命名规范 v0.1

> 接口所有者：张晋辅。任何人改动本规范必须先找他，改完同步更新本文件与 `code/config.py`。

## 一、目录

```
data/
├── raw/                                  # 原始数据：只读，永不修改
│   └── {region_id}/                      # R1_CH / R2_AR / R3_QS
│       └── {instrument}/                 # EUI_HRIEUV / SDO_AIA_193 / HMI_MAG
│           └── {date}/                   # 2021-01-10
│               ├── *.fits
│               └── manifest.csv          # 该目录的文件清单（自动生成）
├── interim/                              # 中间产物：校准后、去尖峰后、裁剪后
│   └── {region_id}/{instrument}/{date}/
└── cubes/                                # 数据立方：可直接加载分析
    └── {region_id}/                      # 一个源区一个 cube
```

## 二、命名规则

- **原始文件保留官方原名**，不重命名。理由：要与官方档案、论文附录对得上号。
- **派生文件**统一为：`{region_id}_{instrument}_{date}_{step}.fits`
  - 例：`R1_CH_EUI_HRIEUV_2021-01-10_l2cal.fits`
- **中间步骤代号**（step）只能用下面几个，别自创：

| step | 含义 |
|---|---|
| `raw` | 原样拷贝 |
| `l2cal` | 完成官方 2 级校准 |
| `despike` | 去宇宙线尖峰 |
| `align` | 差分旋转对齐到参考时刻 |
| `crop` | 裁剪到源区视场 |
| `cube` | 合成时间序列立方 |

## 三、manifest.csv

每个 `raw/{region}/{instrument}/{date}/` 目录下必须有一个 `manifest.csv`，由下载脚本自动生成，字段：

```csv
filename,download_time_utc,size_bytes,sha256,url
```

作用：换机器、换人时能核对「下载是否完整」，不用重下几个 GB。

## 四、时间与坐标

- 所有时间列一律 **UTC**，ISO 8601（例：`2021-01-10T00:00:00Z`）。本地时间不许进事件表。
- 位置列一律 **日面投影坐标（arcsec）**，分别记 `x_arcsec` / `y_arcsec`。
- 做了磁场回映的事件，另填 `cr_lon_deg` / `cr_lat_deg`（Carrington 经纬度）。
- 不做坐标变换的取舍：能直接量就量，量不了留空，**不要瞎换算**。

## 五、禁止事项

1. 往 `data/raw/` 里写任何处理结果。
2. 用含糊的名字如 `test.fits`、`新建文件夹`、`final2`、`真的最终版`。文件名必须能自解释。
3. 把 `data/` 提交进 Git（`.gitignore` 已挡，别用 `-f` 强推）。
